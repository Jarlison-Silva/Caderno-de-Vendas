# Caderno de Vendas

Aplicativo web simples para registrar as vendas do dia e acompanhar o total, feito como projeto de extensão. Funciona direto no navegador do computador ou do celular, sem instalar nada.

**Acesse o app:** https://jarlison-silva.github.io/Caderno-de-Vendas/

## O que ele faz

- Registra cada venda com produto, quantidade e valor unitário
- Mostra o total do dia e a lista das vendas de hoje
- Guarda o histórico dos dias anteriores, com o que foi vendido em cada dia
- Permite remover vendas (de hoje ou de dias anteriores), com confirmação

## Como usar

1. Preencha o item, a quantidade e o valor e toque em **Registrar Venda**.
2. O total do dia é atualizado automaticamente.
3. Para apagar uma venda registrada por engano, toque no **X** ao lado dela.
4. Para ver dias anteriores, abra a seção **Dias anteriores**.

## Importante

Os dados ficam salvos **no navegador do aparelho** (localStorage). Isso significa que:

- o celular e o computador têm cadernos separados;
- limpar os dados do navegador apaga as vendas;
- ninguém mais tem acesso às vendas registradas, mesmo com o link do app.

## Tecnologias

HTML, CSS e JavaScript puros, sem bibliotecas externas.
